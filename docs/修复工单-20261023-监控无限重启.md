1. **P0｜usage-pane 为什么不写心跳**：state/size-usage.txt 长时间不更新是重建的直接触发条件（>8 秒即判死）。usage-pane 进程明明活着（ps 可见）却不写文件——查 usage-pane 自身日志/退出码、launch-usage.sh（login 壳包装）、以及它写心跳的前置条件（是否卡在 go-quota 额度 API 的锁/超时上、python 列合并是否崩）。注意 logs/ 下应有线索。
